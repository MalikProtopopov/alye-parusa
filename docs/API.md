# API

База: `/api/v1`. Интерактивная документация — `/docs` (Swagger), схема —
`/openapi.json`. Ниже — то, чего в Swagger не видно: конвенции и причины.

## Авторизация

```
POST /api/v1/admin/auth/login    {email, password} → {access_token, user}
GET  /api/v1/admin/auth/me       Authorization: Bearer <token>
```

JWT в заголовке `Authorization: Bearer`. Время жизни — из
`ACCESS_TOKEN_TTL_MIN` (по умолчанию 12 часов).

Всё под `/api/v1/admin/*` требует токена. Разделы **настройки, SEO, редиректы,
калькулятор, учётки** доступны только суперадмину; менеджеру они отдают 403.

## Конвенции

**Доли, а не проценты.** Ставки и взносы хранятся как `0.3`, а не `30`.
Переводит на границе интерфейс, не API.

**Относительные пути к файлам.** Поля с изображениями содержат `/media/<имя>`.
Абсолютный URL собирает клиент — это позволяет менять домен, не трогая базу.

**Слаг — часть публичного адреса.** При смене слага бэкенд сам заводит
301-редирект со старого адреса и схлопывает цепочки: если было `A → B`, а стало
`B → C`, то останется `A → C`, а не два прыжка. Обратный редирект (`B → A`)
удаляется, чтобы не получить петлю.

**Мягкое удаление отсутствует.** `DELETE` удаляет запись. Скрыть материал с
сайта — снять галку «Активна» (`active: false`), это не то же самое.

### Заявка

```jsonc
POST /api/v1/leads
{
  "name": "Иван",                  // обязательно, 2–255 символов
  "phone": "+7 999 123-45-67",     // обязательно, 6–32 символа
  "consent_given": true,           // обязательно: согласие по 152-ФЗ
  "consent_text": "Согласен на обработку персональных данных",
  "kind": "with_calc",             // simple_callback | with_calc | without_calc | presentation | floorplan
  "source_block": "calculator",    // откуда отправлена
  "source_button": "Рассчитать",
  "page_url": "https://…/planirovki/studiya-22",
  "message": "…",
  "utm": { "utm_source": "yandex", "utm_campaign": "brand" },
  "floorplan_id": "…",             // если из карточки планировки
  "calc_snapshot": {               // снимок расчёта: что ввели и что посчиталось
    "input":  { "price": 6200000, "down_payment_pct": 0.3, "term_months": 24 },
    "result": { "monthly_payment": 190000, "total": 6700000 }
  },
  "website": ""                    // ловушка для ботов: заполненное поле = спам
}
```

После сохранения фоновая задача отправляет уведомление в Telegram со ссылкой на
заявку в админке. Недоступность Telegram не влияет на ответ посетителю.

Поле `website` — ловушка для ботов: оно скрыто в форме, и если пришло
заполненным, API отвечает успехом, но ничего не сохраняет. Бот не понимает, что
его отсекли, и не пробует другой обход.

## Админские эндпоинты

Для 11 контентных сущностей набор одинаковый — его порождает общая фабрика:

```
GET    /api/v1/admin/{раздел}            список (включая скрытые)
POST   /api/v1/admin/{раздел}            создать
GET    /api/v1/admin/{раздел}/{id}       получить
PUT    /api/v1/admin/{раздел}/{id}       изменить
DELETE /api/v1/admin/{раздел}/{id}       удалить
POST   /api/v1/admin/{раздел}/reorder    порядок: [{id, sort}] → 204
```

Разделы: `news`, `documents`, `faq`, `advantages`, `partners`, `team`, `facts`,
`site-texts`, `hero-chapters`, `plan-categories`, `floorplans`.

Одиночные записи (без списка) — `GET`/`PUT`: `banner`, `contacts`, `calculator`,
`settings`.

Остальное:

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/admin/leads` | заявки: фильтры по статусу, датам, поиск |
| GET | `/admin/leads/count?status=new` | счётчик для бейджа в меню |
| GET | `/admin/leads/export` | выгрузка CSV |
| GET/PATCH/DELETE | `/admin/leads/{id}` | карточка, смена статуса и заметки |
| GET/POST/DELETE | `/admin/media` | медиатека: список, загрузка, удаление |
| GET/POST/PUT/DELETE | `/admin/seo` | мета-теги страниц |
| GET | `/admin/seo-known-paths` | все адреса сайта + флаг «есть SEO» |
| GET/POST/PUT/DELETE | `/admin/redirects` | 301-редиректы |
| POST | `/admin/settings/test-notification` | тестовое сообщение в Telegram |
| GET | `/admin/stats` | цифры для дашборда |
| GET | `/admin/health` | здоровье контента: пустые категории, планировки без фото, отсутствие Политики |

## Ошибки

Помимо стандартных 401/403/404, бэкенд возвращает коды в `detail` — админка
переводит их в понятный текст:

| Код | Когда | Смысл |
|---|---|---|
| `slug_exists` | 409 | адрес занят другой записью |
| `policy_required` | 409 | нельзя снять пометку/удалить единственную активную Политику — на неё ссылаются формы сайта (152-ФЗ) |
| `media_in_use` | 409 | файл используется; в ответе `used_by` — список записей |
| `path_exists` | 409 | редирект с таким «откуда» уже есть |
| `redirect_to_self` | 422 | «откуда» и «куда» совпадают после нормализации |
| `category_not_found` | 422 | указана несуществующая категория планировки |
| `telegram_not_configured` | 400 | не заданы токен бота и chat_id |
| `telegram_send_failed` | 502 | Telegram не принял сообщение |

422 от pydantic приходит массивом `{loc, msg, type}` — админка собирает из него
одно сообщение «Проверьте: …».

## Фичефлаги

Ненужные разделы отключаются переменными окружения (`FEATURE_NEWS=false`,
`FEATURE_TEAM=false`, …). Выключенный флаг убирает и публичные, и админские
маршруты сущности — не прячет в UI, а не регистрирует вовсе.
