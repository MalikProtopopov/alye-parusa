# Карта контента: раздел админки → блок сайта

Шпаргалка «что где меняется». Полезна и разработчику при отладке («откуда этот
текст?»), и контент-менеджеру.

## Главная страница, сверху вниз

| Блок на сайте | Раздел админки |
|---|---|
| Первый экран: видео и текст по главам | **Главы первого экрана** (до 6 активных) |
| Плашка поверх первого экрана | **Баннер** |
| «О комплексе» + цифры проекта | **Тексты секций** → `about`, **Цифры проекта** → группа `about`, **Преимущества** |
| Лента фактов под «О комплексе» | **Цифры проекта** → группа `trust`, заголовок — **Тексты секций** → `trust_band` |
| «Локация» | **Тексты секций** → `location` |
| Лента «рядом» | **Цифры проекта** → группа `nearby`, заголовок — `nearby_band` |
| «Инфраструктура» | **Тексты секций** → `infrastructure` |
| Скролл-история «Жизнь у моря» | **Тексты секций** → `scroll_story` |
| «Апартаменты» | **Тексты секций** → `residences` |
| Избранные планировки | **Планировки** (активные, по порядку), заголовок — `floorplans` |
| Калькулятор рассрочки | **Калькулятор** (условия), заголовок — `calculator` |
| «Инвестиции» | **Тексты секций** → `investment`, **Цифры проекта** → группа `investment` |
| Новости | **Новости**, заголовок — `news` |
| Команда | **Команда**, заголовок — `team` |
| Вопросы и ответы | **Вопросы (FAQ)**, заголовок — `faq` |
| Партнёры | **Партнёры**, заголовок — `partners` |
| Форма заявки внизу | **Тексты секций** → `cta` |
| Подвал: телефон, адрес, реквизиты | **Контакты** |

Врезки с фотографиями между секциями и надписи на них — часть дизайна, из
админки не меняются.

## Отдельные страницы

| Адрес | Чем управляется |
|---|---|
| `/planirovki` | **Планировки** + **Категории планировок** (фильтры) |
| `/planirovki/<категория>` | **Категории планировок** — описание категории идёт в текст страницы |
| `/planirovki/<планировка>` | **Планировки** |
| `/novosti`, `/novosti/<слаг>` | **Новости** |
| `/dokumenty`, `/dokumenty/<слаг>` | **Документы** |

Адрес категории и планировки живут в одном пространстве имён: `/planirovki/xxx`
сначала ищется среди категорий, потом среди планировок. Поэтому слаг категории и
слаг планировки не должны совпадать — при совпадении выиграет категория.

## Служебные разделы

| Раздел | Зачем |
|---|---|
| **Заявки** | обработка обращений: статусы, заметки, выгрузка в CSV |
| **Медиатека** | загрузка картинок, чертежей, PDF и видео; удалить используемый файл нельзя |
| **SEO** | заголовок, описание и `noindex` для конкретного адреса; панель показывает страницы без SEO |
| **Редиректы** | 301 со старых адресов; при смене слага запись создаётся автоматически |
| **Настройки** | счётчики аналитики, коды подтверждения вебмастеров, канал уведомлений |
| **Контакты** | телефоны, мессенджеры, адрес, реквизиты, кадастровый номер |

## Что сломается, если убрать

- **Меньше 6 активных глав первого экрана** — сайт покажет стандартные тексты
  вместо ваших: главы работают только полным комплектом.
- **Нет активной Политики обработки данных** — формы сайта ссылаются на неё по
  152-ФЗ, поэтому снять пометку с единственной активной API не даст.
- **Пустой раздел** (новости, партнёры, команда, FAQ) — соответствующий блок
  просто не показывается на главной, это штатное поведение.
- **Планировка без категории** — не попадёт ни в один фильтр каталога, но
  останется доступна по прямому адресу.

## Как быстро увидеть правку

Сайт кэширует данные и обновляет страницы в фоне — изменение появляется в
течение примерно минуты. Кнопка «Посмотреть на сайте» в админке ведёт прямо на
нужный блок или страницу.
